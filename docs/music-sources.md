## 接入与修正

### 网易云音乐 `netease-music`

- 搜索：`https://music.163.com/api/cloudsearch/pc`，解析标题、歌手、专辑、时长及受限提示。
- 保存身份：`https://music.163.com/song?id=数字`；播放时调用官方 `/api/song/enhance/player/url`，不持久保存会过期的 CDN 链接。
- 媒体仅允许 `*.music.126.net`；接口无 URL 时显示原站不可公开播放，`freeTrialInfo` 非空时标注试听片段并采用片段时长。
- 未采用社区插件中的其他第三方解析兜底。
- 样本：《起风了》（1330348068），接口返回约 326 秒音频，实际读取 4096 字节有效 MP3。浏览器播放、暂停、进度跳转通过。

### 好听轻音乐 `htqyy`

- 社区插件使用 `keyword` 参数，但实测原站会忽略它，返回默认列表。检查原站 `<form>` 后确认参数应为 **`wd`**；本适配器已纠正。
- 仅解析 `.musicItem .title a`，不混入侧栏推荐和重复的“播放”按钮。
- 从播放页读取静态 `var mp3="编号/mp3/1"`，校验编号与所选歌曲一致，不执行页面脚本。
- 媒体为 `http://s1.htqyy.com/play9/编号/mp3/1`，按源站要求带 Referer，由本地服务转发以支持 HTTPS 页面与 Web Audio。
- 样本：「天空之城（小提琴）」，搜索词实际生效，读取 4096 字节有效 MP3；浏览器实际播放显示时长 2:34，暂停正常。

### 原有两个来源

- Internet Archive：详情查询改为每批 3 个并发；过滤私有、受限、过大文件；详情全部失败时报告失败，避免伪装空搜索；允许官方 `*.archive.org` 下载重定向。
- Wikimedia Commons：修复 `application/ogg` 音频被过滤的问题，播放域名限制为 `upload.wikimedia.org`，保留原站文件说明页入口。
- 两者搜索和媒体请求均沿用 `.env` 的 `MOYIN_PROXY`，浏览器访问同源音频接口。
- 两个来源本次样本均完成 4096 字节实际音频读取。具体时间与样本记录在 `data/health.json`。

### 本次未接入

- 街声：插件资料显示公开免登录通道使用 HLS，而现有播放器基于 HTML Audio/Web Audio；接入需额外完成浏览器 HLS 支持，不将 m3u8 当作 MP3 链接注册。
- QQ、酷狗等：查阅的集合有条目，但本次未完成这些平台的独立链路验证。
- Apple Music：曾验证官方搜索接口可用，但只有试听片段；本次优先完成社区找到的中文来源，未注册此源。

## 网站与验证

- 音乐与小说、漫画、番剧作为主页四个同级分类，共用搜索、卡片、详情和收藏；按当前分类同时搜索全部来源，逐源展示结果、失败源提示和原站入口。顶部仍沿用原主页的「主页 / 书库 / 搜索」胶囊布局。
- 四类详情均可打开内容或加入收藏，并支持并发添加去重。音乐播放器保留桌面双栏、手机上下布局，支持续播、从头播放和曲目切换；发现、收藏入口回到统一主页和书库。收藏的在线音乐可继续用于情绪映射，备份保存稳定源站地址。
- 同源流式 `/api/audio` 支持单段 Range、取消上游、100 MB 上限；检查音频类型和文件头，不把 HTML 错误页作为音频交付。健康检测实际读取音频样本。
- `npm test`：覆盖音乐解析、权限提示、音频数据校验、Range、四类统一操作、旧收藏/备份兼容、并发去重、音乐续播、番剧续集续播和迟到请求回归。
- `npm run check:sources -- netease-music htqyy archive-audio wikimedia-audio`：4 个来源样本全部通过。

检测代表当前样本，不表示所有曲目都可播放。在线收藏仍需联网；本地上传或合成的音频可离线使用。
