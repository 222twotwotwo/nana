## 实际修正

- 原项目没有依赖清单，启动脚本指向另一工具内部的绝对路径；已改为 `npm ci` / `npm start`。
- 前端和服务端各执行一套规则，默认选中的旧来源可能失效；已统一固定适配器和稳定 ID。
- 阅友一章被拆成多个 `.con` 区块；必须全部合并，不能仅读取首屏或删除“未完”提示后声称完整。
- 极速漫画桌面详情布局已变，标题应排除评分，章节使用移动阅读地址。
- 漫画源包含 P.A.C.K.E.R 编码的图片数组；新实现只解析字符串数据，不 `eval` 源站代码。
- 旧探活只检查图片数组非空；新检测验证首尾图片实际下载与文件签名，浏览器另验证图片自然尺寸。
- 旧小说批量导入会丢弃失败章节；新版保存完整目录与每个章节的地址，已下载正文逐章持久化并可重试。
- 旧探活没有时间戳且按数组下标绑定；新版按来源 ID 记录时间、样本和错误环节，24 小时后标记过期。
