# nana · 小说、漫画、音乐与番剧

nana 是一个面向个人使用的本地内容应用，把小说、漫画、音乐和番剧放进同一个主页。四个分类共用一套搜索、详情与收藏体验，所有内容数据保存在自己的浏览器里，不需要注册账号，也不依赖任何云端服务。

## 主要功能

- **四类统一主页**：小说、漫画、音乐、番剧同级并列，共用搜索框、结果卡片与详情弹窗；一次搜索并行查询当前分类的全部来源，结果按匹配程度排序，单个来源失败不影响其他结果。
- **收藏与进度**：开始阅读或播放时自动收藏；主页展示「继续阅读 / 继续播放」与最近收藏，四类内容的进度各自续接。
- **离线缓存**：小说章节、漫画图片等按需缓存到本地，已缓存内容断网也能阅读；首次在线打开后应用界面本身也会被缓存。
- **情境配乐**：为小说章节绑定情绪标签的音乐播放列表，阅读时自动匹配氛围。
- **AI 情绪分析**：可选功能，填写自己拥有的 OpenAI 兼容接口后可对章节做情绪分析，用于情境配乐；普通阅读与音乐播放完全不需要 AI。
- **番剧自动换源**：同一集播放失败时自动尝试其他来源的对应集数，保留进度与收藏；也可手动指定来源。
- **备份与迁移**：书库、音乐、进度、分析与设置可一键导出为备份文件，在新浏览器或新设备上一键恢复。

## 内容来源

应用通过服务端适配器接入公开的在线内容来源，当前共 30 余个：

- **小说与文库**：酷我小说、阅友小说、速读谷、笔趣阁、维基文库、轻小说文库等
- **漫画**：漫画人、极速漫画、快看漫画、WEBTOON、MangaDex 等
- **音乐**：网易云音乐、好听轻音乐、Internet Archive、Wikimedia Commons 等
- **番剧**：接入 [KazumiRules](https://github.com/Predidit/KazumiRules) 索引的全部 16 个公开源，如 7sefun、DM84、MXdm 等

所有在线来源的可用性取决于源站自身的版权状态、域名与网络情况。来源检测、缓存与代理回退均由服务端统一处理，浏览器不直接访问来源站点。

## 技术构成

前端基于 Vue 3 构建的单页应用，负责阅读器、漫画、音乐播放器与番剧播放界面；服务端基于 Node.js，统一负责来源搜索、内容解析、缓存与媒体转发。本地数据存放在浏览器的 IndexedDB 与 localStorage 中，收藏记录永不离开本机。

## 数据与隐私

- 书库、阅读进度、收藏与设置全部保存在本机浏览器中，没有账号体系，没有服务器端用户数据。
- 备份文件只存储在本机，导出内容不含 API Key；建议在更换浏览器或清理浏览器数据前先导出备份。
- AI 情绪分析的接口地址与密钥由用户自行填写，仅保存在本地设置中。

## 使用范围

本项目按个人使用目的接入公开可读取的内容，不解锁付费章节，也不绕过登录或人机验证；会员或受限内容请前往原站处理。来源站点规则的授权与其指向作品的授权是两回事，公开商业运营需要另行获得相应的内容授权与运营条件。
