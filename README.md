# nana · 小说、漫画、音乐与番剧

面向个人或小范围自用的本地内容应用。主页提供小说、漫画、音乐、番剧四个同级分类，共用搜索、详情与收藏流程，保留 TXT / 音频导入、情境伴读、AI 情绪分析和主题功能；在线来源统一由 Node.js 服务端访问，浏览器负责阅读、播放和本地保存。

## 启动

需要 Node.js 22 或更高版本（本次验证环境为 24.13.0）。在项目目录运行：

```powershell
npm ci
npm start
```

打开 **http://localhost:8761**。停止时在启动终端按 `Ctrl+C`。原来的 `.server/start-server.bat` 和 `node .server/server.js` 也会启动新版。

默认仅监听 `127.0.0.1`。本机 3655 端口由 WorkBuddy 占用，因此采用 8761；更改 `PORT` 前先导出书库。`localhost`、`127.0.0.1`、不同端口与浏览器均有独立的本地数据空间。

服务启动时自动读取项目根目录 `.env`。本机已配置 `MOYIN_PROXY=http://127.0.0.1:7897`。需要代理的来源继续使用代理；番剧的搜索、目录、取链和视频请求先直连，连接、超时或 HTTP 错误时通过该代理重试一次，仍失败再尝试其他线路或来源。登录限制、无效范围、地址校验失败及主动取消不会触发代理重试。请保持该代理运行。迁移项目时可复制 `.env.example` 为 `.env` 并修改地址，修改后重启服务。不会修改系统代理，也不会关闭 HTTPS 证书验证。

番剧播放页会合并同一集的不同线路，按集名匹配其他来源，保留季数与 Part 区别；旧收藏标题中的“热度”会在打开和换源搜索时清理。换源记录分别显示搜索、目录、播放阶段，视频实际加载后才保存新的收藏来源。HLS 播放器随前端构建发布，播放列表、视频分片和密钥通过带签名的 `/api/video` 地址访问，使浏览器也能使用服务端的代理回退。更新后运行 `npm ci --prefix frontend`、`npm run web:build`，再重启服务并刷新页面。

在播放器上方的「播放来源」选择具体来源，可手动切换同名同季作品的对应集数并保留播放进度。手动模式只尝试所选来源及其备用线路，失败时保留选择并显示原因；选回「自动换源」即可恢复跨源重试。成功加载视频后会保存来源和模式，下次打开继续使用；查找失败不会覆盖原收藏。两种模式都保留直连失败后走代理的策略。

## 四类统一主页

顶部导航沿用原主页的「主页 / 书库 / 搜索」胶囊，更多菜单进入设置。主页的小说、漫画、音乐、番剧使用同一组分类入口、搜索框和结果卡片；搜索会并行查询当前分类全部来源，逐源展示结果，并按完整匹配、前缀匹配和包含匹配排序。单个来源暂时失败不会阻断其他结果，切换分类后旧请求不会混入新分类。

四类详情均提供「开始/继续阅读或播放」「加入收藏」「原站」；开始阅读或播放时自动收藏，已收藏内容可从详情移出。书库使用相同四类分类和卡片，支持标题、作者筛选；主页展示当前分类的继续项与最近收藏。

番剧接入 [KazumiRules](https://github.com/Predidit/KazumiRules) 当前索引的全部 16 个公开源（规则快照 `fce5e15a2e6b57500912d41b3f1c65bb3eb7d392`）：`7sefun`、`aafun`、`AGE`、`akianime`、`baimao`、`dalvdm`、`DM84`、`ezdmw`、`giriGiriLove`、`mgnacg`、`moonci`、`mutefun`、`MXdm`、`sorani`、`xfdmneo`、`xfdmnext`。规则已转换为本项目的搜索、详情、选集接口；可解析的静态播放器地址会经过域名白名单校验，遇到验证码、登录、反爬或站点播放器中转时可点击「原站」。

番剧和其他在线来源的可用性取决于源站版权、域名与网络状态。

## 使用与数据迁移

1. 在主页选择小说、漫画、音乐或番剧，输入关键词，打开结果详情后阅读、播放或收藏。四类内容都在「书库」页管理，已有小说、漫画和音乐数据无需迁移即可继续使用。
2. 小说先保存完整目录，阅读时加载正文并存入 IndexedDB；「缓存前 50 章」逐章保存，停止或失败不会删除目录，已保存的内容仍保留。服务恢复后可重试。
3. 首次在线打开后，应用界面会缓存；同一浏览器再次打开时，已缓存的小说章节可离线阅读。未缓存正文和漫画图片仍需联网。漫画支持章节切换与单张图片重试。
4. 在设置中查看各来源的检测时间、样本和失败环节，点击「重新检测」。一次样本成功不表示全部作品、付费章节都可读取；来源之间不会自动混合章节。
5. 书库每个分类的首位「＋」封面用于添加内容：小说可导入 TXT 或搜索，音乐可导入音频或搜索，漫画和番剧进入对应搜索。音乐分类另可合成氛围音。音乐详情打开播放器，支持续播、从头播放、上一首、下一首和随机播放；播放列表中的曲目可绑定情绪标签用于伴读。AI 情绪分析需要自己填写可用接口和密钥，普通阅读、音乐播放不需要 AI。

「主页 → 音乐」同时搜索全部音乐来源，结果逐源显示，详情与其他三类共用收藏、打开和原站操作。桌面为播放器与播放列表双栏，手机为上下布局；播放器内的「发现音乐」「管理收藏」回到统一主页和书库。播放、暂停、拖动进度和伴读切换沿用同一个播放器。

音频由 `/api/audio` 按来源转发，支持 HTTP Range、代理路由与 Referer；仅允许固定来源域名，单文件上限 100 MB。音乐库保存稳定的源站曲目地址，播放时重新解析短期有效链接；收藏在线曲目不等于下载，离线请使用上传的本地音频或合成氛围音。备份包含曲目来源和情绪标签。

调研项目、未接入原因和验证细节见 [音乐源调研与接入记录](docs/music-sources.md)。音源可用性以源站当前权限与网络状态为准，会员或受限内容在原站处理。

```powershell
npm run check:sources -- netease-music htqyy archive-audio wikimedia-audio
```

**旧版迁移：** 原目录的 `index.html` 现为迁移入口。请在以前使用旧版的同一浏览器、同一地址打开它，导出备份，再到新版「设置 → 恢复备份」。备份含书库、音乐、分析、进度与设置，不含 API Key；恢复合并记录，同编号记录被替换。旧地址的数据不会自动删除。

新旧版本都使用 `novel-reader` 数据库。原四个已启用来源的 `srv:*` 编号有固定兼容映射；未知旧漫画来源需在主页重新搜索，旧小说已缓存正文仍能阅读。番剧收藏和播放进度也纳入同一备份格式。备份文件只存储在本机，建议在换浏览器或清理浏览器数据前导出。

## 验证与维护

```powershell
npm test               # 无外网依赖的回归测试
npm test --prefix frontend # Vue 番剧标题、换源与续播回归测试
npm run check:sources  # 实际搜索→目录→正文/图片，刷新 data/health.json
npm run check:sources -- sudugu kuaikan  # 只重测指定来源 ID
npm run audit:upstream # 重新检查仓库版本、规则格式与首页连通性
```

检测失败时 `check:sources` 以非零状态退出。设置页的检测一分钟内复用同一结果，超过 24 小时显示过期。服务端搜索缓存 5 分钟、目录 1 小时、漫画图片列表 5 分钟、小说正文 30 天；缓存最多约 100 MB / 2000 条，并在启动和每小时清理。浏览器书库为个人数据，不随服务端缓存清理。

目录结构：

```text
public/             四类主页、收藏、阅读/播放、设置、备份和离线界面缓存
server/sources.js   原四个来源适配器、全部来源注册
server/additional-* 新增小说、文库、漫画、番剧和音乐适配器
server/kazumi-rules.json KazumiRules 当前索引的 16 条规则快照
server/kazumi-anime.js   Kazumi XPath/API 规则的静态适配器
server/community-music.js 中文社区音乐源适配（网易云、好听轻音乐）
server/audio.js     音频数据校验、范围请求与流式传输
public/catalog.js   四类共用搜索、卡片、详情与收藏操作
public/music.js     音乐取链、试听标记与续播
public/anime.js     番剧选集、播放与观看进度
server/source-data.js Nuxt 页面数据解析（不执行上游 JavaScript）
server/network.js   请求超时、大小限制、域名与网络地址约束
server/service.js   缓存、来源检测、兼容编号与图片校验
server/index.js     HTTP 接口与固定公开文件列表
scripts/           实际来源检测与上游评估
test/              解析、服务端和浏览器逻辑回归测试
data/              检测结果与可丢弃的服务端缓存
.server/           旧规则文件保留作参考；server.js 为新版兼容入口
```

接口：`GET /api/health`、`GET /api/sources`、`POST /api/action`（source/action/value）、`POST /api/check`（source）、`GET /api/image`（source/url/referer）、`GET /api/audio`（source/url，支持 Range）。静态服务只暴露固定 `public/` 文件。原通用抓取代理、客户端自定义脚本执行和第三方 CORS 代理已退出运行路径。

## 容器运行（可选）

```sh
docker build -t moyin .
docker run --rm -p 127.0.0.1:8761:8761 -v moyin-data:/app/data moyin
```

Dockerfile 已提供，本次环境未实际运行容器验证。默认本地服务没有多用户账号、跨设备书库同步或公网访问认证，不应作为公开 SaaS 直接部署。小范围共享应先在可信网络中配置访问控制；局域网 HTTP 不支持离线 Service Worker，需要 HTTPS 才能使用这一能力。

容器不会复制本机 `.env`。Docker Desktop 中需要代理时，另传 `-e MOYIN_PROXY=http://host.docker.internal:7897`，并确保代理允许容器连接；容器内的 `127.0.0.1` 指向容器自身。

## 使用范围

上游两个仓库均提示不用于商业用途，书源规则和所指向作品的授权是两回事。本项目按个人使用接入公开可读取内容；不解锁付费内容或绕过登录、人机验证。公开商业运营需要另行获得内容授权及运营条件。
