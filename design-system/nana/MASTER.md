# nana 视觉规范

以现有主页为基准：浅灰画布、白色面板、黑色标题、暖橙点缀、胶囊按钮和柔和阴影。使用 ui-ux-pro-max 的简洁布局、主题令牌、清晰状态与响应式建议；主页的实际样式优先于技能推荐的新配色或字体。

## 基准与公共样式

- 主页及库墙继续使用现有 `.home-heading`、封面墙与继续阅读卡片。
- 设置、情境配乐使用 `.page-heading`；标题桌面 38px，手机 30px，与主页一致。
- 公共卡片圆角 `--radius-card:18px`，输入框 `--radius-field:10px`，按钮 `--radius-pill:999px`。
- 卡片沿用 `--panel`、`--line`、`--shadow`；弹窗使用 `--shadow-lg`。
- 系统中文无衬线字体用于界面；阅读正文保留宋体与原有字号、行距。
- 使用 `AppIcon` 的 SVG 线条图标，装饰图标隐藏于辅助技术，独立按钮提供名称。

## 主题颜色

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 `--bg` | `#fafafa` | `#101012` |
| 面板 `--panel` | `#ffffff` | `#1b1b1e` |
| 正文 `--text` | `#181818` | `#ececec` |
| 辅助文字 `--text-secondary` | `#6b6b70` | `#aaaab2` |
| 强调色 `--accent` | `#c8622e` | `#e08a4f` |
| 实心主按钮 `--accent-solid` | `#b85425` | `#e08a4f` |
| 主按钮文字 `--on-accent` | `#ffffff` | `#181818` |

主页原有辅助文字颜色保留。情绪颜色用于状态圆点，标签文字使用主题文字色。阅读菜单、悬浮播放器与常规页面共用面板风格；音乐黑胶和视频画面保留内容本身的表现形式。

## 响应式与交互

- 手机断点保持 760px；音乐双栏在 761–1100px 缩小内边距，避免播放器内横向滚动。
- 表单和章节操作允许换行；辅助说明与长来源地址允许折行。
- 主要图标按钮为 44px；手机设置、情境配乐、选集及弹窗按钮至少高 44px。
- 阅读菜单展开时暂时隐藏音乐浮层，关闭菜单后恢复，避免遮挡操作。
- 沿用 `motion.css` 的动效时长与减少动态效果设置；悬停、选中和按压颜色使用主题变量。

后续页面优先复用这些公共样式，不引入新的字体、页面配色或独立按钮体系。
