## 修复 Vue 重构版全局无法滚动 + 阅读悬浮栏消失

- 根因：Vue 挂载层 `#app` 包裹了 `header/main`，打破了原版 `body`（flex column + overflow:hidden）的直接子元素布局链，`main` 拿不到高度，内容被裁剪
- 修复：`style.css` 增加 `#app{display:contents}`，让挂载层不参与布局（仅此一行 CSS 改动）
- 验证：主页 919>566 可滚、阅读器 1017>578 可滚、设置页可滚；`#fabBar` 恢复右下角（"目录 · 0%"），rdMenu 菜单（章节目录/情境配乐/主题与设置 + 三圆钮）与旧版一致
- 教训：SPA 挂载点若插在 body 与原布局根之间，必须处理挂载层对 flex/height 链的影响

## 番剧播放失败自动换源

- 背景：7sefun 部分集数是 lmm85 会员播放器（player_aaaa.from==='vxdev'），服务端有意不绕过登录限制，报"该集需要在 7sefun 原站登录后播放"——是源的限制不是 bug
- 实现：`services/anime.ts` 新增 findAlternativeAnime / autoSwitchAnimeSource；AnimePage 播放失败时自动遍历其他番剧源（SOURCES.type==='anime' 共 15 个），按标题指纹匹配同名作品（canonSeason 统一 Ⅲ/第三季/season3 → 「季N」、Part.2/第2部分 → 「pN」），换源后保持 book.id 不变（进度连续）并 dbPut 写回收藏持久化
- 匹配坑：toLowerCase() 会把 Ⅲ (U+2162) 变成小写 ⅲ (U+2172)，罗马数字映射必须含大小写
- E2E 验证：写入 7sefun 第三季收藏 → 播放第1集失败 → 自动切到 DM84 → 成功加载 mp4（23:40）；标题匹配单测 8/8（frontend/scripts/test-match.mjs）
- UI：换源过程显示"「XX」无法播放（原因），正在尝试其他源…"；全部源失败后显示错误 + "重试（重新换源）"（清空 failedSources）

## 换源深查：修复两个服务端 bug + 网络环境结论

- 用户质疑 Kazumi 规则源（xfdmnext 等）没生效 → 实测发现两个真 bug：
  1. `server/service.js source()` ID 归一化错误：传 `kazumi-MXdm` 会拼成 `kazumi-kazumi-mxdm` → 404"未接入"。修复：归一化时剥掉 kazumi- 前缀再比对
  2. 媒体流白名单过严：`service.js:78` 对 play 结果用固定 CDN 白名单（gtimg/qq 等），MXdm 的 yzzy28-play.com 被误杀。修复：`network.js` 新增 `mediaAllowed()`（白名单优先、退回公网协议校验，SSRF 由 directDispatcher 公网 DNS 检查兜底），番剧 play 链路统一使用；52 测试全过
- xfdmnext 结论：规则与 Kazumi 官方最新版完全一致（同 apikey）；之前不可达是用户开着 TUN 模式（fake-ip DNS 198.18.x）干扰 TLS 握手，关闭 TUN 后直连恢复（Mushoku 单词能搜到）；但其站内检索不支持中文关键词，中文搜索 0 条——源站限制
- 源可用性实测（搜"无职转生"）：可用 9 个 = 7sefun/DM84/akianime/baimao/moonci/ezdmw/MXdm/aafun/AGE；搜不到中文 7 个 = xfdmnext（英文可搜）/xfdmneo/dalvdm/girigirilove/mutefun/mgnacg/sorani
- Kazumi 能播而本项目不能的源：规则标 useWebview:true 的（akianime 等）依赖 App 内 WebView 执行 JS，纯 HTTP 抓取无法解析
- 最终 E2E：7sefun 收藏 → 播放失败 → 自动换 DM84 → 视频 23:40 加载成功（docs/refactor-screens/final-e2e.png）
